44. **A counted `for` loop carries a checked measure as a fact beside the
    resource verdict; every other loop carries a named refusal; no verdict
    reads either.** Card W45-FB-ENGINE-PROGRESS-MEASURE
    (`crates/qcore-c-gateway/src/loop_measure.rs`; thin hooks in
    `qcore-audit`'s `projection.rs` (`record_loop_measures`), `report.rs`
    (`write_loop_measure_selection`) and `checkpoint_run.rs`). (1) **The
    selection.** `QCORE_LOOP_MEASURE_PROPERTY=<rows.jsonl>` selects the
    property and names its JSON-lines output (beside it,
    `<rows>.summary.json`), as the bounds and null selections do; unset,
    nothing runs and every artifact is byte-identical. A checkpointed run
    refuses the selection, and a checkpointed fragment holding rows is
    refused. A row is `{library, file, function, custody, loops, identity}`
    (`loop-measure.v1`, model `qcore-loop-measure/1`); `custody` is the
    status the report's own unit row publishes after every fold, read when
    the rows are written. Each loop (`for`, `while`, `do`, a macro loop at
    its use) is at its original `file:line` (`origin`, through the gateway's
    preprocessed line map) with a `measure` or a `refusal` code and detail.
    (2) **The admitted shape**, read from Clang's typed AST of the
    preprocessed text (a macro constant is a literal after Clang's
    preprocessing, never read lexically): a `for` loop whose step is exactly
    `c++` or `++c`; `c` an automatic, non-volatile local or formal of a
    standard integer type other than `_Bool`, whose address is taken nowhere
    in the function and which nothing else in the loop (condition, step,
    body, nested statements) writes; init exactly `c = c0` or `T c = c0`,
    `c0` a constant representable in `c`'s type; a condition `c < B` or a
    top-level `&&` chain with such a conjunct, `B` a Clang-evaluated constant
    (literal, `ConstantExpr`, enumerator, or `sizeof(a) / sizeof(a[k])` /
    `sizeof(*a)` over a one-dimensional array whose extent Clang's type
    states), a *stable* local (automatic, non-volatile, never address-taken,
    not written in the loop) or a value of an unsigned type at most 16 bits
    wide (its type bounds it even when it changes); every conversion Clang
    recorded to the comparison's type preserves values; `B`'s value or type
    range lies within `c`'s type; the function calls no returns-twice
    function and has no inline assembly or block literal; the loop contains
    no label and no `case` of a `switch` outside it. `break`, `return`, a
    `goto` out and `continue` are admitted. (3) **The fact.** The measure
    `B - c` is positive while the test holds and strictly decreases by one
    per iteration; the loop runs at most `max(Bmax - c0, 0)` iterations
    (`Bmax` the constant or the maximum of `B`'s type); the smallest admitted
    conjunct is recorded. (4) **Refusals**, each named: `no-counter`,
    `step-not-increment`, `counter-not-local-integer`,
    `counter-address-taken`, `opaque-control`, `label-in-loop`,
    `counter-written-in-loop`, `init-not-constant`, `test-not-less-than`,
    `comparison-converts`, `counter-may-wrap`, `bound-written-in-loop`,
    `bound-address-taken`, `bound-not-stable`. **Do not** read a loop fact
    into any verdict (custody, bounds, null, numeric), present it as a
    progress, termination of the body, latency or throughput claim, admit a
    bound whose address is taken anywhere in the function unless its narrow
    unsigned type alone bounds it, read a macro constant from the source
    text, or derive a list length (the list-finiteness premise PL is not a
    local fact; rule 48 records a list-length bound only under a declared
    premise whose frame the unit establishes, in its own `list_bound`
    field). Premises stated, not
    proved (trust boundary 28): Clang's JSON AST is read faithfully (types,
    recorded conversions, referenced declarations, literal values, location
    de-duplication in document order) and the target integer model is the
    analysing Clang's for the unit's flags (rule 11q). `QCore.CountedLoopMeasure`
    (`measure_positive_while_running`, `measure_strictly_decreases`,
    `step_stays_in_counter_range`, `run_length_bounded`,
    `an_admitted_shape_meets_the_premises`, the refusal theorems
    `a_wrapping_counter_never_exits`, `a_written_bound_never_exits`,
    `an_aliased_counter_reset_never_exits`, `a_double_increment_never_exits`,
    `a_less_or_equal_test_never_exits`, `recording_a_fact_keeps_the_verdict`,
    `decide_vectors_hold`), bound to `DECIDE_VECTORS` and the fixtures
    (`tests/loop_measure.rs`, `qcore-audit/tests/loop_measure_selection.rs`);
    [report](../reports/w45-fb-engine-progress-measure/README.md).
