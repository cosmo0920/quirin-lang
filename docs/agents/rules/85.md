85. **An in-out slot is a keep-or-deliver summary only when both entries
    validate; a caller reads it only by branching on its own slot.** Card
    OUT-SLOT-CONDITIONAL-DELIVERY (`legacy_keep_or_deliver_summary.rs`,
    `legacy_keep_or_deliver.rs`, `qcore_schemas::keep_or_deliver`). USER
    DECISION 2026-11-25: "lanich four of queued cards", choosing the
    return-family and this-lane set, which includes this card. Rule 74l's
    `Out` reading refuses `if (!*out) *out = make();` (the exit that keeps the
    slot is `Unwritten`). (1) **The callee.** Consulted after every other
    route published nothing (W4, member effect, retention, lifetime,
    exit-specific, forwarding), for a singleton component with exactly one
    formal it stores through. The body is built with a null test of exactly
    that slot (`*NAME`, `!*NAME`, `*NAME ==`/`!= NULL`) read as a branch on
    the slot's binding, only while this validation builds it, then run twice:
    from the slot seeded null, where the bind loop must settle fully `Safe`
    and the slot read W4's `Out { nullable }` (`out_mode`); and, on the CFG
    rebuilt with that delivered contract as its own (rule 4b), again from
    null under the unchanged W4 gate, and from the slot holding a fresh live
    non-null caller-held site `S`, where every exit must still hold `S` in
    the slot, live and non-null, and the unchanged W4 gate must pass with the
    slot read `Owned { nullable: false }` on `S` (no containment under `S`,
    no result handing it back). A store over a non-null slot (a partial-path
    store, a slot first holding another object's member, a second store), a
    release or hand-off of the kept object fails the second run. (2) **Where
    it lives.** The summary `(slot, delivered)` goes to the environment's
    keep-or-deliver table, never the function map, so every consumer that
    does not read it (records, cross-unit imports, callback candidates,
    indirect calls) sees an uncontracted function. The callee's own row is
    unchanged (rule 74l's refusal). (3) **The caller.** A whole-statement
    call `F(…, &NAME, …);` or `D = F(…);` that the classifier refused as
    uncontracted is lowered to `if (NAME == NULL) F(…, &NAME, …); else F(…,
    NAME, …);`, the arms classified under minted names (reserved spellings)
    carrying the delivered contract and the kept one (the slot position
    `Owned { nullable: false }` on `NAME`), then renamed `F`. The flow
    decides the branch: a known-null `NAME` takes custody of the delivery, a
    held live object stays the caller's and is never minted twice, and any
    other value reaches the kept arm with no live identity and refuses
    (`Unknown`). Any other call of `F` is refused as `call to `F`, whose
    summary keeps or delivers its in-out slot, outside the direct-call
    reading (an actual other than `&NAME`)`. (4) **Refused, named.** A slot
    first holding another object's member, then a fresh object
    (`rd_kafka_assignment`, `rd_kafka_subscription`): the member store
    overwrites a held object, and `return err` does not partition the early
    unwritten exits; stating it needs the op's member custody or a
    caller-pre-null convention that amends rule 74l, a user decision. A
    failure store the status does not partition (`cio_file_native_lookup_*`:
    a store, a second store over it, failure exits holding an object or
    nothing): no reading states it, refused. A store partitioned by an
    explicit literal status keeps rule 11r(6)'s reading. **Do not** read the
    kept arm as `Borrowed` or the delivered arm as an `Out` of a non-null
    slot, publish the summary into the function map, or apply the slot-test
    reading outside the validation's build. Premises stated, not proved:
    faithful token and Clang extraction (trust boundary 28), and that the
    branch the lowering adds tests the value the callee's slot holds at
    entry. `QCore.OutSlotKeepOrDeliver` (`keep_or_deliver_vectors_hold`,
    `a_read_mode_keeps_on_every_owned_exit`,
    `an_overwrite_of_the_kept_object_reads_no_mode`,
    `a_fresh_object_only_for_a_known_null_slot`,
    `an_unplaced_slot_is_unknown`, `the_reading_is_the_effect`,
    `the_kept_arm_mints_no_second_custody`,
    `an_out_reading_mints_a_second_custody`,
    `a_borrowed_reading_hides_a_delivery` and six more), bound to
    `KEEP_OR_DELIVER_VECTORS`; `tests/out_slot_keep_or_deliver.rs`;
    [report](../reports/out-slot-conditional-delivery/README.md).
