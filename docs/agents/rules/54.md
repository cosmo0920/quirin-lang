rule: 54
topic: gateway
summary: A whole read of a thread-local (`__thread` / `_Thread_local`) object of object-pointer type, copied into an automatic local, is a custody-free value (the reading `pthread_getspecific`'s `return_none` result gets): the copy holds no binding, no obligation is created or discharged; the reading is withheld for the whole function when the object is written, address-taken, a record or array, dereferenced or passed to a call, or a copy is used other than as a copy, a `return`, a null test or a rebinding.
---

54. **A whole read of a thread-local pointer object is a custody-free value,
    exactly as `pthread_getspecific`'s result is.** Card
    THREAD-LOCAL-CUSTODY-FREE-READ, on the user's decision of 2026-11-16
    ("Queue both (Recommended)", option D1 of CURRENT-CONTEXT-NEW-TRIAGE's
    proposal) (`thread_local_read.rs`: `admitted`, `decide`; the unit
    index's `thread_local_declarations` in `typed_access_path.rs`; one
    `Alias` arm in `legacy_transfer::transfer_base`; the CFG field
    `thread_local_reads`, asked only where the unit spells `__thread` or
    `_Thread_local` before the body's end, so a unit with neither needs no
    Clang AST for it). It completes rule 11h (3) for a copy into a
    local: a static- or thread-duration object's value carries no identity,
    and route G already admitted it handed straight out (`return t;`), but
    a copy (`evl = flb_engine_evl; return evl;`, Fluent Bit's `FLB_TLS_GET`
    with `FLB_HAVE_C_TLS`) took the generic alias route and refused as an
    unresolved identity, while the `pthread_getspecific` build of the same
    getter was `Safe` (its `resource_return_none()` result drops the
    destination's binding). (1) **Objects.** A name is a thread-local
    object of a function when every reference to it is to a `VarDecl` Clang
    marks thread-local (`tls`; a file-scope one from the unit index, or a
    block-scope one) and no other declaration of the function spells it.
    Its **copies** are the automatic locals (block scope, no storage-class
    specifier, not thread-local, not a parameter, every declaration of the
    name automatic) that receive its value by a plain `=` or an
    initializer, closed under copying between them. (2) **Admission, for the
    whole function.** Every object is of object-pointer type at every
    reference (not an array, a record, a function pointer, `volatile` or
    `_Atomic`); every reference to an object is a whole read (lvalue
    conversion, through parentheses and pointer-preserving casts) consumed
    by a plain `=` into a copy, a copy's initializer, a `return` operand or
    a null test (`==`, `!=`, `!`, `&&`, `||`, a condition); every reference
    to a copy is the target of a plain `=` or a whole read consumed in those
    four positions. Anything else withholds the reading for the function: a
    write to the object (`=`, a compound assignment, `++`/`--`: a
    take-from-thread-local would hide a transfer behind a custody-free
    value), `&` of it, a `.` or `->` member, a dereference or subscript of
    the object or a copy (a store, release or transfer through it), a call
    actual (any callee may release or transfer it), any other use. (3)
    **Transfer.** Where admitted, `COPY = OBJECT` and `COPY = COPY'` from a
    source with no binding drop the destination's binding, the transfer of
    a `return_none` call: no obligation is created or discharged, the value
    is borrowed, and every custody use of it finds no binding and refuses
    (a release or transfer of the copy, in the body or in a caller of a
    getter that returns it, is never credited and never accused). Where
    withheld, or where the source holds a binding, the alias transfer is
    the old one. **Do not** read a static (non-thread-local) object, a
    member of a thread-local record, an array, or a formal destination
    under this rule, give the value an identity or an owner, or state a
    teardown or a retained-result relation (`pthread_setspecific` /
    `pthread_getspecific`'s relation stays open,
    `W43-RESULT-ALIAS-CONDITIONAL-AND-RETAINED`). Premises stated, not
    proved: faithful Clang extraction of the `tls` field, declaration ids,
    types and parent nodes, and route G's lowering of a copy as one alias
    node (trust boundary 28); a whole read of a thread-local object yields
    what an earlier store of this thread left there (C11 6.2.4p4).
    `QCore.ThreadLocalRead` (`decision_vectors_hold`,
    `admitted_exactly_on_a_custody_free_use`,
    `a_write_to_the_object_withholds`, `a_use_through_it_withholds`,
    `the_copy_is_the_return_none_reading`,
    `the_copy_changes_no_obligation`, `a_release_of_the_copy_refuses`,
    `returning_the_copy_escapes_nothing`,
    `the_withheld_answer_is_unchanged` and four more), bound to
    `DECISION_VECTORS` by a shared-vector test
    (`tests/thread_local_custody_free_read.rs`);
