63. **A condition leaf's residual read beside identity calls is decided by
    the typed read; an uncontracted call that refuses a condition names its
    callee.** Card AG3-CONDITION-RETURN-CALLS (round 33,
    `legacy_condition_leaf_reads.rs`, a child of `legacy_condition_desugar.rs`
    reached through two thin hooks there: `leaf_plan`'s residual decision and
    `planned_condition`'s last route; a `refused_call` field on
    `DesugarState`). Amends rule 5h's residual premise and, for controlling
    expressions, extends rule 12k's re-attribution.
    (1) **The residual read.** In a call-bearing leaf with no assignment,
    outside a `switch`, whose residual (each call replaced by `0`) the neutral
    route refuses, the residual is read by `condition_access` (the typed
    condition read of rules 5h-5l, lexical, never the Clang node matcher,
    which cannot match a residual) when **every** instruction the leaf's calls
    lowered to is the identity on the abstract state: an identity contract
    call (`is_identity_call`: every position borrowed, no container effect, a
    `None` or derived result, no produced site, no aggregate effect) or an
    actual read with no destination and no frame. The decision is the read
    itself (`IndirectScalarAccess`, no destination, no frame): it keeps every
    base's flow obligation and refines neither edge, because the residual's
    `0` is not the call's value. C leaves the order of a leaf's call and its
    operand reads unspecified; with identity calls every order reaches the
    same state and checks the read's obligations against it
    (`QCore.ConditionLeafReads.every_order_reaches_the_same_state`,
    `the_read_sees_the_same_state_in_either_order`). (2) **The named
    refusal.** When the position's routes, the desugaring, the elaborator
    (rule 10s) and the `va_arg` route (rule 12c) all refused, and the
    desugaring's refusal was a leaf call the classifier refused with exactly
    ``call to uncontracted function `F` `` for that call's callee `F` (named
    in the condition), the position's refusal node is replaced by a one-node
    plan holding `Unknown` with the description ``call to uncontracted
    function `F` in branch condition`` (`loop`, `for-loop`, `do-while`
    for the other positions), the condition's writes and both exits, which
    the planned compilers wire exactly as the refusal node was wired (loop
    exit edge, header, `continue` target, cell test). The position suffix is
    load-bearing: the refused-operand hand-on rule
    (`legacy_refused_operands.rs`, `refuses_a_condition`) reads a refusal's
    position from its text, and without the suffix a refused condition would
    hand on the statement table of its line and withdraw a leak accusation
    (measured on a one-line fixture; `the_named_text_keeps_the_condition_class`).
    **Do not:** admit a residual read beside a call that is not the identity
    (a release, consumption, owned or reallocated result, container effect),
    beside an assignment (`(n = f(x)) > p->len` keeps rule 10x's split or its
    refusal), in a `switch`, or through the Clang node matcher; use the read
    to refine an edge; re-attribute any other classifier text (an indirect
    actual's `indirect memory access …` stays the position's text, which is
    AG1's subject), a held call, a recursive-component or custody refusal, a
    `switch`, or a condition that reads a tracked descriptor. Premises stated,
    not proved: faithful token extraction and the classifier's answers (trust
    boundary 28), and that an identity call's effect on the abstract state is
    its contract's (constraint 4). Fixtures:
    `tests/condition_leaf_reads.rs`. `QCore.ConditionLeafReads`;
    [report](../reports/ag3-condition-return-calls/README.md).
