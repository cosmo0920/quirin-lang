topic: gateway
summary: A member invocation (`resource_callback_member_invoked(OBJ, TAG.FIELD, A…)`, C04.19.3) is decided only over the closed set of stores into the member: in the unit (open or empty: `callback-member-open`), then the run's fold keeps a Safe or Pending row only when the run's set is closed and contained in the unit's (premise P-CG22-MEMBER-CLOSED-WORLD); every unit of the run is read, a data-only unit whole for its facts, and only a unit whose AST is not read opens a member (CALLBACK-MEMBER-DATA-ONLY-UNITS); the fold never promotes; a checkpoint composer refuses such a run unless its checkpoints carry the run's facts. The unit's closed set also orders the W4 derivation (its candidates are summarised before a caller), so a formal released through the call reads as a tracked local. Since OP-APP-RK-CALLBACKS-VIA-POLL-CB: a member is keyed by its innermost named record and a union's members share one key; a setter's `resource_callback_member_registered(P, TAG.FIELD, F)` and a constructor's stated function default are stores; the pinned route's pre-pass reads every production unit naming a token of the closure (scope file `member-facts-scope.json`), each unit decides over the run's set, and a run-closed empty set invokes nothing (premise `P-RK-NO-PLUGIN-LIBRARY` on the rk_conf declarations). Since MEMBER-PREPASS-OTHER-ROUTES: the current and no-build routes run the same pre-pass over their compile databases, a checkpoint (schema 5) carries the run's facts and its composer folds them (refusing without them), and every scope-file exclusion is re-verified against the run's sources and final tokens, a stale one dropped. Since RKO-OP-CB-RUN-SET-OPEN-THROUGH-UNION: a union's places keep their arm path (`U.*@arm`) and are kept apart only on disjoint bytes of Clang's record layout read by the pre-pass; a range the layout does not give, or two units' differing layouts, stay shared. Since UNION-OPAQUE-RECORD-WRITES-BY-TYPE: an opaque write of a record is keyed by its target (a place a union holds decides by its own bytes; a separate object or a path below a record no union holds never keys into a union; an untargeted write keeps the type reading), and a declared path into a union keeps its arm.

    unit's closed set orders the W4 derivation** (card
    RETAINED-RELEASE-OF-A-FORMAL-READ-UNKNOWN):
    `callback_route::callback_edges` gives a body that calls a
    member-invoking declaration an edge to every in-unit function of the
    member's closed set in its unit (an open set adds none), so the
    candidates are summarised before their caller. Without it a formal
    released through the call read `UnknownAlias`: the caller's summary was
    derived first, read the candidates as uncontracted there and refused, so
    the reported run (which decides the member as for a tracked local) never
    bound the formal. This is ordering, not a soundness guard: whether a
    candidate may alias the formal is answered, in every run, by its own
