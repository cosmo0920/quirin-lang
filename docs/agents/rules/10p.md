---
rule: 10p
topic: gateway
summary: A loop-owned collector operation (`resource_loop_owner`) is admitted only where the thread-entry census derives every caller context on its loop's owner with no unresolved hop; every route that derives no thread refuses it. A coroutine runs on its derived resumer (hop C); a body that may yield after it is unresolved; a conditional arm is dropped only when the build configuration decides it. A field dispatch reaches only registrants of the Clang record type it goes through (untyped sites field-keyed, unmatched ones refused); a plugin copy's instance drops the coroutine route only when both its creating plugin's and the copy's flags derive none; a list-head instance is tied to its creation only by a derived single creation on the test's path, an escaping holder only when it can write neither the flag nor the instance, and P-CALLBACK-INSTANCE is derived at every dispatch. A literal-keyed property setter call reaches only the branches its keys take, the key table, comparison and branch chain read from the source; anything unread keeps the whole call. A reserved macro is decided per compile command only from the recorded compiler (probe, `-dM`, `-E -dD`); a mismatched or unavailable compiler or a failed derivation decides nothing, and a value comparison is never evaluated. P-CORO-HANDLE, P-PLUGIN-DIR and the immutable threaded flag are derived from the typed reading (handle confined to the coroutine's own functions, descriptor flags and `is_threaded` written only where derived, registrations on the plugin's own instances); an underived one keeps every route, directory flag or mode it would decide. The premised census derives the list-head instance's fresh context and registered descriptors (the generated registration read), narrows the head to the creations' success, checks P-INSTANCE per site (a refuted one unresolved) and refutes the flag on a byte or whole-object write of an instance or collector. With region-macro facts every invocation on the list-head region is read from its unit's own token dump and the census graph gains every macro-made call; the holder's pointer is followed from every read of the instance's `data`, a write through it outside the holder's file keeping the route.
