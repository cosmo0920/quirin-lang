## Planned mechanism the forecast assumes

- **Step A, positions.** P2's Clang-typed reader, unchanged in its refusals, as
  a fallback after every existing route in: a call-free controlling-expression
  operand (`if`, `while`, `do`, `for`, `switch`), wired through the existing
  condition desugaring so `&&`, `||` and `?:` scope each operand's obligations
  to the edges where C evaluates it; one `NAME = PATH` assignment operand
  followed by the existing null branch on `NAME`; a single-read `return`
  (a scalar path, or a pointer-valued path read only from roots the body never
  binds, with a `NoOp` exit); and a call actual at a `Borrowed` or declared
  data-tail position of a contracted or summarized callee. Returns with `&&`,
  `||`, `?:`, casts inside the path, assignments or calls stay refused, and an
  array member returned by decay is an interior address and stays refused.
- **Step B, the owner-aware enum arm**, measured separately: a value typed
  `enum TAG`, or a typedef whose declaration is directly an `EnumType`, counts
  as a scalar. Unions and unknown aggregates stay refused.
