DISCOUNTED THREE-WAY PREDICTION PER CAUSE
  (1) leaf-free   (2) exchanged for another refusal   (3) unmoved
==============================================================================
Method. For a candidate cause C -- a reader change that committed the
declared type of every base blocked by C -- take every function
carrying a leaf one of whose statements has a chain blocked by C. It
is predicted leaf-free only if:
  - its only blocker family is this one; else UNMOVED;
  - every chain of every statement of every leaf it holds in this
    family is either already Committed or blocked by C; else UNMOVED,
    because the chains C does not reach still refuse;
  - and no such statement carries an UNCONTRACTED call; else
    EXCHANGED, because admitting the access leaves the statement
    facing the uncontracted-call gate.
This is GENEROUS in one further way the shape-level prediction was
not, and it is stated rather than buried: committing a base's type
yields a TAG, not an admission. The member must then classify, and
the access rule must then admit it. So CLEAR is an upper bound on an
upper bound -- see the record-body cross-tab above for the one cause
where the second question can be asked.
