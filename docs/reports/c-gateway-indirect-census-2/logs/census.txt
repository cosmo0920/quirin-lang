==============================================================================
PREDICTED THREE-WAY SPLIT PER CANDIDATE SHAPE
  (1) leaf-free   (2) exchanged for another refusal   (3) unmoved
==============================================================================
Method, stated so the numbers can be checked rather than believed.
For a candidate shape S, take EVERY function carrying a leaf whose
statements include shape S. It is predicted leaf-free only if:
  - its only blocker family is this one; otherwise UNMOVED, because
    another family still refuses it;
  - every statement of every leaf it holds in this family has shape S;
    otherwise UNMOVED, because the leaves S does not cover remain;
  - and no such statement carries a call to an UNCONTRACTED function,
    nor a second access chain of a different shape; otherwise
    EXCHANGED, because admitting the access leaves the statement
    facing the uncontracted-call gate, or a second access S does not
    cover. A call the analyzer already has a contract for is NOT an
    exchange: the statement's remaining decision is one the projection
    can already make.
The exchange test is a PROXY. It errs toward calling a function
exchanged rather than cleared, so the CLEAR column is a lower bound on
nothing and an upper bound on what a wave-37 arbiter could hope for;
it is a scoping estimate, not a measurement of that arbiter's result.
Shapes are ranked by predicted DECIDED FUNCTIONS, not by leaf mass —
ranking by leaves is exactly the error this card exists to prevent.
