## Source review and exact effect

Four revision-flexible libc declarations (`memcmp`, `strncmp`, `strnlen`, `strcasecmp`) use the audited host's glibc `/usr/include/string.h:75,174,445` and `/usr/include/strings.h:116` prototypes. The two input pointers are read, lengths are scalar, and no pointer is stored, acquired, released or returned. The declarations assert no byte validity, bounds, equality, or string termination fact. All four are resource-contract catalog additions; the 185-unit baseline has no uncontracted-call leaf for these names, so this card does not claim a libc corpus gain.

Seven pinned declarations in `monkey/scalar_observation.qcore` have the same borrowed-arguments/no-result-custody shape. `_mk_string_search` (`mk_string.c:211-264`) and `mk_string_char_search`/`_r` (`:267-297`) scan strings and return integer offsets. The private helper is the uncontracted call in two public wrappers. `MK_EVENT_NEW` (`mk_event.h:140-144`) writes only `mask` and `status`; it neither initializes nor releases the remaining fields. Vendored Libevent `event_base_get_features` (`event.c:584-587`) reads the feature field; `event_get_struct_event_size` (`:2527-2530`) and `event_get_version_number` (`:3569-3572`) return compile-time scalars. The reviewed Monkey and vendored Libevent source files are byte-identical between Fluent Bit `66910c10a4d7eafa810b84229cf2dcf7b0f26f97` and `046accf6aded7906f66a1baf0202da349e521736`. Libevent's independent pinned submodule is `d82464a277d0f42703702c4dfd9af6af38595a83`; those three bodies have separate source identities in `contracts.lock`. The pin tool examined every found definition/declaration site in each checkout, including duplicate vendored copies.

## Controls and boundaries

`w46_libc_event_contract_gaps.rs` loads the production files byte for byte. Seven accepting C bodies are Safe under the selected declarations and become uncontracted when the module is removed. A heap actual passed to the borrowed search still leaks; a released actual is never Safe. The libc catalog control confirms the four new names have only borrowed parameters and no result custody. `QCore.ScalarObservationContracts` and its `AuditScalarObservationContracts.lean` prove and audit the neutral shapes for the seven pinned declarations; the source/body fidelity and Lean-to-Rust correspondence remain reviewed premises.

Declined: `event_get_events`, `event_get_priority`, `event_get_fd`, `event_get_base` and callback/argument getters call `event_debug_assert_is_setup_`; with debug locks configured, it can invoke user lock callbacks, so unconditional neutral custody is not established. Base event-count/priority queries take configured locks too. Event creation, registration, dispatch/wait and handles retain or act on custody outside this card. `mk_event_backend` chooses a backend body and returns a static literal; it was left out pending review of every backend-selected arm and exact result handling. `getrlimit`/`setrlimit` stay declined under the existing unreadable `__rlimit_resource_t` ABI gate, as measured by W46-EXTERNAL-CALLEE-CONTRACTS. No speculative declaration was made for these gaps.
