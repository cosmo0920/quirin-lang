[Report index](../../../INDEX.md)

RULE50-CONSUMER-COMPOSITION added the contract clause
`resource_member_helper(P, TAG.PATH, H)` (gateway rule 51, grammar G05d,
contract specification §C04.19.6) without a user decision on its spelling, and
registered `MEMBER-HELPER-CLAUSE-SPELLING` for that decision
([card report](../rule50-consumer-composition/README.md)).

name. Nothing changes in the loader, the provider contracts, the pins, the
rule text or the Lean model; the follow-up is retired.
