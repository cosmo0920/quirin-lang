# Additional approved bounds/null attachment boundary

Root approved this necessary scope extension after the census established 71
bounds-v1 sites outside the generic resource-only API. This freeze precedes any
bounds implementation. Final exact Graph-v2 merged-base refresh remains due.

Use only existing `requires resource_hypothesis` and
`requires resource_premise_decomposition` graph-v2 metadata heads. The bounds
loader validates complete declaration-local graphs against its own original
`BoundsClause::Premise` values. Attachments add no `BoundsClause`, extent,
nonnull/precondition, frame, canonical semantic digest or solver decision.
Text/pin digest still binds every written metadata clause. Wrong placement,
missing legacy target, malformed/dangling/reordered/cyclic metadata and wrong
module vocabulary refuse. Resource loading of bounds modules stays rejected.

Replay and explicit binding manifests use independently held property-specific
source maps. Never combine resource and bounds maps keyed only by function:
exactly two selected function names overlap. Bounds/null graphs are freshly
reconstructed from the actual retained bounds sources. Null publication attaches
refinements only from the row's actual named-premise dependency through-records;
it never selects all refinements by name alone or infers a dependency from a
lexical match. Each candidate attachment must match exact legacy text and its
held property/source declaration. Original null premise/carrier/through vectors,
legacy graph nodes, body standing and all classification facts are preserved.

No new public schema field or version is planned: use existing Graph2 and
binding types, with additive separately named property-specific replay helpers.
Any need for a public schema expansion is coordinated before implementation.
Source bindings and trace interpretation remain Open; invalid reference records
refuse evidence, never turn any verdict into Unsafe. No bounds/null solver or
callback-effect implementation is part of this metadata extension.

Prediction: all 166 original occurrences gain the same seven proposed atoms
and one attachment after strict property-specific replay; the two outer module
sources remain byte-identical. After graph-metadata attribution, every full
null property dictionary, static/combined/runtime record, legacy premise vector,
closed-world fact, and declaration/clause standing must match on six fresh
paired routes. Actual full rows and every changed field are retained. Exact
source/pin/root/environment/configuration/time identity changes need producer
reconstruction, not normalization by dropping fields. Mathematical Lean proves
publication/erasure noninterference, guarded conjunction consequences and exact
context impact; it does not prove source/model equivalence or premise truth.
