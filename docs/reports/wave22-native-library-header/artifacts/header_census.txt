# Rows are one per header. `cand` is every identifier the text writes
# immediately before a `(` (`native_library_header::census_candidates`), so the
# denominator is a statement about the header rather than a curated list;
# `absent` is therefore a real row — a call inside a macro body is a candidate
# too. `reason` lines tally the offending token of each unreadable position.
#
# Libevent rows are the pinned submodule (third_party/libevent, d82464a).
# msgpack/chunkio/monkey rows are pinned Cycle 19 build inputs read from
# build/cycle19/wave20-pin/fluent-bit-clang-source/ (docs/CYCLE19_BUILD_INPUTS.md);
# those files are not of this repository, so their counts are reported here and
# their *shapes* are pinned as fixture rows instead. The Libevent rows are pinned
# in CI by compiler/tests/native_library_header.rs.
