BYTE IDENTITY, measured rather than asserted
--------------------------------------------

The BASE COMMIT's compiler was built in a scratch tree (measure/baseline.sh,
`git archive a53fe2a4`) and used to emit the C of every .qcore file under
compiler/tests/fixtures/ and examples/ that emits at all.  The card build was
then run over the same inputs with the same spelled paths and compared byte for
byte (measure/compare.sh):

    byte-identical: 65   differ: 0   no-longer-emits: 0

ALL 65 PROGRAMS THAT EMIT ARE BYTE-IDENTICAL.

A measurement hazard, recorded because it cost a full re-run: the first
comparison reported 16 differences, every one of them a `#line` directive
carrying the SPELLED INPUT PATH --- the baseline had been emitted with absolute
paths and the card build with relative ones.  Standing constraint 11 is exactly
about this ("do not normalize the spelled input path --- that changes
__FILE__"), so the TOOL was corrected to use one spelling rather than the
compiler to use one path.

ENVIRONMENT FINDINGS
--------------------

1.  TWO WORKSPACE RUNS WERE KILLED BY THE ENVIRONMENT, not by this card, and
    are recorded rather than hidden.  Both were started as background tasks and
    both received SIGTERM (exit 143) after roughly the same elapsed time, at 52
    of the tree's ~190 suites.  Neither had reported a single failure at that
    point.  NO NUMBER IN THIS FILE COMES FROM EITHER OF THEM.  The run recorded
    above was started in the foreground and allowed to move to the background on
    its own, which is the shape the card's very first exploratory run had taken
    --- and that one had completed normally.

2.  ONE EARLIER RUN WAS INVALIDATED BY THIS CARD'S OWN EDIT and was stopped
    deliberately: a diagnostic-quality fix (one refusal per loop rather than one
    per failing iteration, §9.9 of the report) landed while it was in flight.
    The STD-BUFFER precedent governs: a run with a source change under it is not
    a measurement.

3.  Machine contention.  Three sibling agents were running against neighbouring
    worktrees for most of this card's closing measurements, and the host was
    under memory pressure.  Wall-clock timings here are therefore not comparable
    with a quiet run.  Nothing about the results depends on that.

4.  NONE of standing constraint 16's five load-sensitive rows tripped.  No
    assertion was weakened and no test was re-run in isolation to obtain a pass.
