# EXT-03 prediction amendment before physical rename

The original [prediction](prediction.md) expected 257 live runtime sources and five ABI manifests to move, while 182 archived source inputs stayed at `.qcore`. The user subsequently explicitly directed that outdated frozen historical source files be changed or removed to prevent confusion. That instruction overrides the repository's usual frozen-archive preservation rule for this migration. We will **rename**, rather than delete, each mapped archived source to keep its content and replay input available. Existing historical digests, verdict records and prose that describe an older checkpoint remain factual evidence; they must not be rewritten to pretend the old checkpoint had new names. Current runnable commands and links are updated to the renamed path, with provenance clearly separated.

The parser inventory selects by `proposed_new_path` suffix: **421** runtime `.qcore` sources propose `.qr` (407 parsed executable, nine parsed library, five intentional parse refusals with `.qr` candidates), of which 257 are live and **164 are under `docs/reports/`**. The two malformed archived `module contract;` attribution fragments propose `.qv` and belong to EXT-02. Five live ABI manifests propose `.qrlib`. This card therefore expects **426 exact source/ABI renames**, preserving bytes for every runtime source. ABI manifest bytes may change only for reviewed native-reference path updates and explanatory comments; their old and new SHA-256 digests will be attributed. No legacy source copy is left in place merely to exercise compatibility tests. The existing parser refusal fixtures must continue to refuse for the same reasons, and no Unknown result may become Safe through path migration.

This amendment was written and committed before any physical rename. The EXT-01 compatibility gate remains the prerequisite for performing the moves.
