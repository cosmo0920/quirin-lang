# Subset census of card NATIVE-LIBRARY-HEADER-DECORATION, measured by the
# shipped reader over the pinned Libevent submodule (third_party/libevent,
# d82464a). Rows and columns are card NATIVE-LIBRARY-HEADER's
# (docs/reports/wave22-native-library-header/artifacts/header_census.txt):
# `cand` is every identifier the text writes immediately before a `(`
# (native_library_header::census_candidates), so the denominator is a
# statement about the header rather than a curated list.
#
# Three blocks. The first is this card's own re-measurement of the wave-22
# reading; it differs from that card's archived rows in exactly two cells
# (event2/buffer.h cond 4 -> 2, absent 0 -> 2), because the erasure
# vocabulary now applies to the unread conditional stream too and `printf`
# inside `__attribute__((format(printf, 2, 3)))` is no longer counted a
# conditional-only declaration. The archived wave-22 rows are NOT edited.
#
# The second block declares ONE text, event2/visibility.h, and nothing else
# changes. The third declares event2/util.h as well, and is the fail-closed
# boundary: util.h carries `#error`, so every header that includes it
# refuses as a file rather than being read in part.
#
# `erasures derived` lists the names the reader concluded are erasable
# declaration decorations from the declared texts' own `#define`s. No
# manifest states any of them.
