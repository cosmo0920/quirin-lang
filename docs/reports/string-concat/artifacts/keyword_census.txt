Card STRING-CONCAT — constraint-14 keyword census
=================================================

Scope: every `.qcore`/`.qc` file on disk (418 at census time, 420 after this
card's two new files) plus every tracked `.rs` and `.md` file. The shape that
matters is the CONTEXTUAL one — the word immediately followed by `(` — because
that, and not the bare word, is what this card's rule skips in name resolution.

Reproduce from the repository root:

    find . -path ./.git -prune -o \( -name '*.qcore' -o -name '*.qc' \) -print | wc -l

    grep -rho --include='*.qcore' --include='*.qc' \
      -E '\b(concat|borrow_utf8|freeze_utf8|utf8|join|append|compose|build)\b' . \
      | sort | uniq -c | sort -rn

    grep -rn --include='*.rs' --include='*.qcore' --include='*.qc' --include='*.md' \
      -E '(^|[^A-Za-z0-9_.])concat\(' . | grep -v '^./target'

    grep -rn --include='*.rs' --include='*.qcore' --include='*.qc' \
      -E 'borrow_utf8|freeze_utf8' . | grep -v '^./target'

    grep -rn --include='*.rs' --include='*.qcore' --include='*.qc' \
      -E '(^|[^A-Za-z0-9_.])(dec|hex)\(' . | grep -v '^./target'

2. The contextual `WORD(` shape, across every tracked file
----------------------------------------------------------

    concat(        0 matches
    borrow_utf8(   0 matches
    freeze_utf8(   0 matches
    dec(           0 matches
    hex(           0 matches

Zero across `.rs`, `.qcore`, `.qc` and `.md`, `target/` excluded. Rust's own
`concat!` macro is a different token (`concat!`) and its `.concat()` method is
preceded by `.`, which the pattern excludes; neither appears in these counts.

Conclusion: **this card reserves no word.** `concat` and `borrow_utf8` join
`len` as contextual clause words skipped by name resolution only where they are
immediately followed by `(`; `dec` and `hex` need no rule at all, having been
reserved since STD-MODULES. The narrow rule collides with nothing, and both
words remain ordinary binding names away from a `(` — pinned by
`the_two_contextual_words_are_reserved_nowhere`.
