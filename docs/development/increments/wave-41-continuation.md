**`CONTRACT-INHERIT` (2026-09-24).** Added contract inclusion and inheritance to the Quirin contract language: `#include "CRATE:MODULE";` header directives and `extern fn … contract inherit [NS::]NAME;`. The contract loader resolves both against an explicit published load path and elaborates them into hand-written-equivalent text before any consumer parses the module; the structural parser keeps refusing both (still `Q000`), so an unresolved inclusion never reaches an unwired consumer.
