**`W44-BRANCH-CONDITION-CALLS` (2026-09-25).** Made calls inside `if`, `while`, `for`, `do`-`while` and `switch` conditions decidable where every call is modeled. A condition every existing route refused is desugared (`legacy_condition_desugar.rs`, a child module of `legacy_c` behind thin hooks): each call becomes its own `ContractCall` from the ordinary statement classifier, in C evaluation order, each operand decides through one branch, and `&&`, `||` and `?:` become edges, so a later operand's calls run only on the edge where C evaluates them; `!` swaps exits and `__builtin_expect(E, K)` reads as `E`. `(NAME = CALL(...))` into a plain declared scalar or pointer local becomes the statement and a test of `NAME`. Uncontracted calls, custody results, same-component local callees, unsequenced effectful pairs, type operators and unadmitted operands keep the refusal, and `if ((p = malloc(n)) == NULL)` keeps today's exact lowering. The census came first (`df5edb61`, rule compiled in and not consulted, byte-identical): most call-bearing conditions fail on a call the classifier refuses (an indirect argument, 1,686 leaves at AFTER; an uncontracted callee, 1,000) or on a call-free operand (1,211), not on a connective. Lean `QCore.ConditionCallDesugar` (25 audited theorems) proves the plan performs exactly C's short-circuit evaluation for every operand valuation. The arbiter removed **292** condition leaves (276 forecast on Unknown functions, exact), exchanged 36 into same-line `unknown_alias` (`unlikely(!x)` on an unresolved name) and decided one false leak on `rd_malloc`'s null edge in `snappy.c`: **0 function or unit moves, leak 271 → 270, 0 violation candidates**. It retired `W43-INDEX-TRAVERSAL-CONDITION-CALL` and registered eight blocker-sized residuals, a derived-result decision and a B02 descriptor-read finding (345 → 354).
