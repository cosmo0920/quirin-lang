**`W43-DESCRIPTOR-RESOURCE-TRACKING` (2026-09-25).** Made resource custody kind-indexed and tracked file descriptors as integers. Resource vocabulary version 1 gains `resource_kind(p, KIND)` and `resource_return_kind(KIND)` for `descriptor`, `stream` and `directory`; the heap is spelled by the absence of a clause, so every earlier module loads, serializes and prints exactly as before. A `descriptor` sits on an `i32` and spells its validity `sentinel`/`valid` (contract spec §C04.6). The C gateway discharges an obligation only with a release of its own kind — a resolved mismatch (`free(fopen(…))`, `fclose(malloc(…))`) is an `invalid_release` candidate — narrows a descriptor's validity from `fd < 0`, `fd == -1`, `fd >= 0` and their mirrors, lets `fd > 0` narrow its true edge only and refines nothing on `if (fd)` or `fd == 0`, and reports a `use_after_release` candidate for a released descriptor or stream used at a declared position. One predicate, `descriptor_custody::value_carries_descriptor`, decides whether a value carries a tracked descriptor; every statement reading one is refused unless its instruction states the effect exactly, so the member, aggregate and indirect scalar stores, the unbound scalar-field no-op and the scalar-source publication exemption no longer treat it as data, and a descriptor handed to a callee only a W4 summary covers is refused. W4 infers no kinded summary. Lean `QCore.KindedCustody` (30 audited theorems) models the kinds, sentinel validity with a soundness theorem for the comparison table, the scalar-route refusal and all-heap conservativity. `quirin-provider-libc` declares `open`, `close`, `socket`, `fopen`, `fclose`, `fileno`, `opendir` and `closedir` (new `libc/dirent.qcore`), each agreeing wherever a captured unit declares it; ten callees are refused by name, `dlopen`/`dlclose` because the return route reads `return (T *)p;` as returning nothing (`RETURN-CAST-PLACE-NOT-ESCAPED`). Arbiter: BEFORE byte-identical; the vocabulary and gateway alone leave all five artifacts byte-identical; the declarations remove 60 leaves and add 43, all attributed. `ctr_random_get` and its unit move Unknown → provisional Unsafe (an `if (fd > 0)` guard abandons descriptor 0), one leak in `mk_rconf_read` is withdrawn by refusal, the leak pin stays 272, and no function moves to Safe. Declarations 130 → 138; follow-ups 299 → 303 (`W43-LIBC-DESCRIPTOR-LIFECYCLE` retired, `CT-CTWIN-O` and `EXTERN-CALL-F` amended, five registered).
