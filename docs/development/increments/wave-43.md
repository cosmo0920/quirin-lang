**`W43-DESCRIPTOR-NATIVE-CHECK` (2026-09-25).** This card adds native observation of the descriptor lifecycle. `docs/reports/w43-descriptor-native-check/harness/descriptor_observer.c` is linked with `-Wl,--wrap`, the method used by the cycle-19 allocator hooks, and wraps 112 libc entry points: every descriptor constructor, release and use for eight kinds (fd, `FILE *`, `DIR *`, dl handle, addrinfo, mapping, `popen` stream, ifaddrs). Each event records the call, arguments, result, errno and injected flag, each operand's kind, identity and generation (reuse is a new generation), the call site and a short stack, and the `fdopen`/`fileno`/`dirfd` relations. Failure injection is deterministic and site-targeted. The targets are relinked from a byte-identical copy of the pinned Fluent Bit checkout under its pinned configure command; all 1,415 compile-database entries match. The runs cover the upstream `tests/internal` pipe, file, network, fstore and utils tests, the `fluent-bit` binary (dummy, tcp with filesystem storage, HTTP server, dynamic plugins), a driver for the actual Monkey `mk_socket.c` functions, and a libc probe for the callees that no Fluent Bit path reaches. Of **77 pinned runs** (36 injected), 76 are accepted with 6,730 records. The records are replayed by the new `qcore_contract::descriptor_observation` under the policy `library/descriptor_native_observation.qcore` (corpus 108 → 109), which has ten rules evaluated by the shared predicate interpreter. No use after release, release-matches-kind, a well-defined leak set, generation discipline, sentinel validity, relations and mapping extents hold on every run. **Release at most once fails in 11 runs**, from two source-confirmed upstream double closes: `flb_config_exit` closes the manager channel's generation through two names, and `flb_sched_destroy` closes each timer descriptor twice. Each second close was answered with `EBADF` only. `close(-1)` occurs in 37 runs. The one rejected run surfaced a heap double free of the ChunkIO context after a storage-scan failure, reproduced without injection with an unreadable `storage.path`. Also observed are a Monkey `mk_socket_server` socket leak on bind failure and a proxy dl handle that is never released. All five are native-observation findings with stated scope, not static verdicts. Lean `QCore.DescriptorNativeObservation` has 25 audited theorems (at-most-once release, no use after release, release kind, well-defined leak set with origins). The Rust replay has 16 tests, 3 of them over pinned real runs. The corpus arbiter is byte-identical and no verdict moved. Phase B is waiting for W43-DESCRIPTOR-RESOURCE-TRACKING. 8 follow-ups registered, none retired: ledger 299 → 307 on the card branch; 313 → 321 after merging main at `0a07cb57`. [Report](../../reports/w43-descriptor-native-check/README.md).

**`W43-INDIRECT-ACCESS-GENERAL` (2026-09-24).** Generalised W42's bounded `BASE->FIELD = scalar` route into one typed rule. The census came first, and it was extended with the `indirect-census` feature's statement stream. It found that the brief's `*p = '\0'` is not in the indirect family but in the store-through and unsupported-assignment families, so five families were measured statement by statement. Admitting any syntactic shape wholesale would decide at most 81 functions. The frozen forecast for the typed rule was 985 leaves and 11 functions. The rule is consulted only after the classifier refused a statement for its access, destination or increment, or named an unsanctioned `*p` store. It admits a statement whose every access is `*p`/`p[i]` over a declared `SCALAR *p` or `SCALAR p[N]`, `p->f` over a declared record pointer and scalar member, or `s.f`, with a scalar destination and value and no call, `&`, comma or pointer increment. Transfer is custody-neutral. Each base must be unbound, a non-null untracked binding, or exactly one known non-null live identity (derived results included), else `UnknownAlias`. A released base is a `use_after_release` candidate from the settled states. A write through `*p`/`p[i]` keeps the refusal's constraint-10a frame. Bounds and constness are outside the property (spec L18, the report's scope field). Lean: `QCore.IndirectScalarAccess` (31 theorems, audited). Arbiter: BEFORE is byte-identical, and 1,112 leaves are removed and 83 added, all attributed: 985 forecast rule leaves, 98 two-base member copies the forecast mirror missed, 1 unreached node, 16 summary call leaves, 12 downstream, 78 exchanges, 5 summary-side refusals and 0 violation candidates. Functions go 257 / 84 / 4,493 → 269 / 84 / 4,481 (12 Unknown → Safe, among them `mk_string_dup`'s allocate-test-fill), and units go 2 → 3 Safe (`cmt_time.c`). The leak pin moves 272 → 271: a false leak in `rd_kafka_snappy_java_uncompress` is withdrawn because a framed store replaced a blanket poison and the release before it is now credited. The gate records 5,222 core Rust, 171 Lean audits, 327 root Python and 109 provider tests, all green, with the census feature now linted and tested in CI. The card retired `INDIRECT-CENSUS-FEATURE-UNBUILT`, `BASE-TYPE-READER-CENSUS-FEATURE-UNBUILT` and `INDIRECT-EXCHANGE-PROXY-UNVALIDATED`. It registered twelve residuals, one per refused shape with its measured size. Follow-ups go 297 → 306 on the card branch; 304 → 313 on integration after the three contract cards.
