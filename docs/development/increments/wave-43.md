**`W43-DESCRIPTOR-NATIVE-CHECK` (2026-09-25).** This card adds native observation of the descriptor lifecycle. `docs/reports/w43-descriptor-native-check/harness/descriptor_observer.c` is linked with `-Wl,--wrap`, the method used by the cycle-19 allocator hooks, and wraps 112 libc entry points: every descriptor constructor, release and use for eight kinds (fd, `FILE *`, `DIR *`, dl handle, addrinfo, mapping, `popen` stream, ifaddrs). Each event records the call, arguments, result, errno and injected flag, each operand's kind, identity and generation (reuse is a new generation), the call site and a short stack, and the `fdopen`/`fileno`/`dirfd` relations. Failure injection is deterministic and site-targeted. The targets are relinked from a byte-identical copy of the pinned Fluent Bit checkout under its pinned configure command; all 1,415 compile-database entries match. The runs cover the upstream `tests/internal` pipe, file, network, fstore and utils tests, the `fluent-bit` binary (dummy, tcp with filesystem storage, HTTP server, dynamic plugins), a driver for the actual Monkey `mk_socket.c` functions, and a libc probe for the callees that no Fluent Bit path reaches. Of **77 pinned runs** (36 injected), 76 are accepted with 6,730 records. The records are replayed by the new `qcore_contract::descriptor_observation` under the policy `library/descriptor_native_observation.qcore` (corpus 108 → 109), which has ten rules evaluated by the shared predicate interpreter. No use after release, release-matches-kind, a well-defined leak set, generation discipline, sentinel validity, relations and mapping extents hold on every run. **Release at most once fails in 11 runs**, from two source-confirmed upstream double closes: `flb_config_exit` closes the manager channel's generation through two names, and `flb_sched_destroy` closes each timer descriptor twice. Each second close was answered with `EBADF` only. `close(-1)` occurs in 37 runs. The one rejected run surfaced a heap double free of the ChunkIO context after a storage-scan failure, reproduced without injection with an unreadable `storage.path`. Also observed are a Monkey `mk_socket_server` socket leak on bind failure and a proxy dl handle that is never released. All five are native-observation findings with stated scope, not static verdicts. Lean `QCore.DescriptorNativeObservation` has 25 audited theorems (at-most-once release, no use after release, release kind, well-defined leak set with origins). The Rust replay has 16 tests, 3 of them over pinned real runs. The corpus arbiter is byte-identical and no verdict moved. Phase B is waiting for W43-DESCRIPTOR-RESOURCE-TRACKING. 8 follow-ups registered, none retired: ledger 299 → 307. [Report](../../reports/w43-descriptor-native-check/README.md).
