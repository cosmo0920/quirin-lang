**`W43-INDEX-TRAVERSAL` (2026-09-25).** Made buffer and string walks decidable for the resource property only (custody, use after release, invalid release), with no bounds claim in the scope string or spec L18. On W43-INDIRECT-ACCESS-GENERAL's merged tip, a traversal census (a new stream of the `indirect-census` feature, inert byte for byte) carried the answers of the very recognisers the admission uses, and the forecast was frozen before any rule was wired: at most 13 functions. A refused controlling expression whose every access is typed lowers to the typed read with each base's obligation (short-circuited operands included). `p++`, `p += e`, `p = q ± e` lower to a pointer step, interior-derived from the source binding with a new `Stepped` marker: it owns nothing; a forward-stepped release is an `invalid_release` candidate, one that may sit at the start (a backward or variable step, or a loop header joining the base identity) is refused, a use after the base's release is a `use_after_release` candidate, and stepping a live object's only identity in place refuses. `*p++ = c` and `buf[i++] = c` lower to the access then the step or forget. A declared scalar's fact joined with no fact is no fact, and a local pointer's copy of an unbound local is unbound (a formal's keeps its refusal, the signal W4 binds on). A soundness hole in the merged base was repaired: a typed index could write (`out[m++]` kept `m == 0` and could prune a reachable `return`, certifying a leak). **`W43-INDIRECT-ACCESS-GENERAL` (2026-09-24).** Generalised W42's bounded `BASE->FIELD = scalar` route into one typed rule. The census came first, and it was extended with the `indirect-census` feature's statement stream. It found that the brief's `*p = '\0'` is not in the indirect family but in the store-through and unsupported-assignment families, so five families were measured statement by statement. Admitting any syntactic shape wholesale would decide at most 81 functions. The frozen forecast for the typed rule was 985 leaves and 11 functions. The rule is consulted only after the classifier refused a statement for its access, destination or increment, or named an unsanctioned `*p` store. It admits a statement whose every access is `*p`/`p[i]` over a declared `SCALAR *p` or `SCALAR p[N]`, `p->f` over a declared record pointer and scalar member, or `s.f`, with a scalar destination and value and no call, `&`, comma or pointer increment. Transfer is custody-neutral. Each base must be unbound, a non-null untracked binding, or exactly one known non-null live identity (derived results included), else `UnknownAlias`. A released base is a `use_after_release` candidate from the settled states. A write through `*p`/`p[i]` keeps the refusal's constraint-10a frame. Bounds and constness are outside the property (spec L18, the report's scope field). Lean: `QCore.IndirectScalarAccess` (31 theorems, audited). Arbiter: BEFORE is byte-identical, and 1,112 leaves are removed and 83 added, all attributed: 985 forecast rule leaves, 98 two-base member copies the forecast mirror missed, 1 unreached node, 16 summary call leaves, 12 downstream, 78 exchanges, 5 summary-side refusals and 0 violation candidates. Functions go 257 / 84 / 4,493 → 269 / 84 / 4,481 (12 Unknown → Safe, among them `mk_string_dup`'s allocate-test-fill), and units go 2 → 3 Safe (`cmt_time.c`). The leak pin moves 272 → 271: a false leak in `rd_kafka_snappy_java_uncompress` is withdrawn because a framed store replaced a blanket poison and the release before it is now credited. The gate records 5,222 core Rust, 171 Lean audits, 327 root Python and 109 provider tests, all green, with the census feature now linted and tested in CI. The card retired `INDIRECT-CENSUS-FEATURE-UNBUILT`, `BASE-TYPE-READER-CENSUS-FEATURE-UNBUILT` and `INDIRECT-EXCHANGE-PROXY-UNVALIDATED`. It registered twelve residuals, one per refused shape with its measured size. Follow-ups go 297 → 306. [Report](../../reports/w43-indirect-access-general/README.md).
